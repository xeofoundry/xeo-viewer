xeokit viewer web component

The whole BIM viewer is a single <xeo-viewer> element. It sits in the page like any other block, the text above and below is ordinary page content.

Usage

Load the bundle once, then place the element and give it a height:

<script type="module" src="xeo-viewer.js"></script>

<xeo-viewer
  model="https://example.com/model.xkt"
  metadata="https://example.com/model.json"
  primary-color="#18947dff"
  compact
  style="height: 600px"
></xeo-viewer>
  • model: URL of the XKT file. Without it the viewer shows its file picker and accepts dropped files.
  • metadata: optional URL of the model's JSON metadata.
  • Both attributes are read once, when the element is added to the page.
  • modelBuffer: optional JavaScript property (not an HTML attribute) taking the XKT file as an ArrayBuffer, for example document.querySelector('xeo-viewer').modelBuffer = buffer. Each new buffer is loaded as another model.
  • metadataBuffer: optional property taking the JSON metadata as an ArrayBuffer of UTF-8 text. Set it before modelBuffer.
  • primary-color: optional CSS color for buttons, active tools and selection, violet by default. Changing it restyles the viewer right away.
  • compact: optional boolean attribute that tightens spacing and text so the viewer takes less room. It can be added or removed at any time.
  • Size it with CSS like a block element. Without a height it is 480px high.
  • A page holds one viewer.
  • The model server must allow requests from the page's origin (CORS).
